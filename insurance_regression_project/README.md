# Medical Insurance Cost Prediction — Regression Project

A machine learning project that trains and compares three regression models to predict
medical insurance charges, with a Streamlit app for deployment.

See `ERRORS_FOUND_AND_FIXED.md` for a full list of issues found in an earlier draft
of this project and how each one was fixed.

---

## Setup & Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the notebooks (in order)
All notebooks must be run from inside the `notebooks/` folder, in this order:
```bash
cd notebooks
jupyter notebook
```
Run in this order: `1_preprocessing.ipynb` → `2_EDA.ipynb` → `3_modeling.ipynb` → `4_evaluation.ipynb`.
Each notebook reads the output of the previous one, so running them out of order will fail.

### 3. Run the deployment app
```bash
cd app
streamlit run streamlit_app.py
```
This opens a browser window where you can enter patient details, pick a model
(Linear Regression / Decision Tree / Random Forest), and get an instant cost prediction.

**Important path rule:** every notebook and the app assume they are run from their own
folder, so all internal paths start with `../` (e.g. `../data/raw/insurance.csv`,
`../models/...`). Running a file from a different working directory will cause a
"File Not Found" error.

## Dataset
- **Name:** Medical Cost Personal Datasets (`insurance.csv`)
- **Source:** https://www.kaggle.com/datasets/mirichoi0218/insurance
- **Size:** 1,338 rows, 7 columns, target column = `charges`

## Models & Results

| Model | R² | MAE | RMSE |
|---|---|---|---|
| Linear Regression | 0.886 | 2,829.0 | 4,572.8 |
| Decision Tree | 0.892 | 2,693.3 | 4,461.4 |
| Random Forest | **0.901** | **2,414.5** | **4,261.8** |

All four notebooks were executed end-to-end with no errors (verified run, not just written code).

### What actually improved performance
- **Interaction feature (`bmi_smoker`)**: raised Linear Regression's R² from 0.807 to 0.886.
- **Log-transform of the target**: tested and rejected — it made R² worse (dropped to 0.588,
  even with a Duan's smearing bias correction). This is documented in `1_preprocessing.ipynb`.
- **Wider GridSearchCV grid**: small additional improvement for Decision Tree and Random Forest.
